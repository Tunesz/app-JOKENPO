# ✊🖐️✌️ App Jokenpô

Aplicativo Android nativo desenvolvido em Kotlin no Android Studio para jogar Pedra, Papel e Tesoura contra a máquina.

## 🚀 Como funciona
1. O usuário escolhe entre **Pedra**, **Papel** ou **Tesoura**.
2. O aplicativo gera uma jogada aleatória para o computador.
3. O app valida as regras do jogo e exibe a mensagem de Vitória, Derrota ou Empate na tela.

## 🛠️ Tecnologias
- **Linguagem:** Kotlin
- **Plataforma:** Android Studio
